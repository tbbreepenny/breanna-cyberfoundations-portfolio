## In My Own Words

**What is the cybersecurity landscape, and why does it matter?**

```
The cybersecurity landscape is the whole environment that security professionals operate in, it includes the systems being protected (hardware, operating systems, software, networks, cloud infrastructure), the people who use those systems, the threats and attackers trying to exploit them, and the tools, policies, and practices used to defend against those threats. It's not one single thing, it's more like an ongoing, shifting picture made up of technology, risk, and human behavior all interacting at once.
Understanding the cybersecurity landscape early matters because it shapes how you think about problems going forward. Instead of treating security as a single skill or checklist, it becomes a mindset of looking at systems holistically and asking where the weak points might be, which is exactly the kind of thinking labs like this one are meant to build.
```

**How do hardware, OS, and software layers interact?**

```
A good example is something like opening Chrome. Chrome, as software, asks the OS for things like memory or network access. The OS takes that request and manages it, deciding how to allocate CPU time and memory alongside everything else running at the same time. Then the CPU, as hardware, actually does the physical work of processing those instructions. None of these layers work in isolation, hardware provides the raw capability, the OS manages and coordinates that capability, and software is what actually uses it to do something useful for the person using the computer.
```
